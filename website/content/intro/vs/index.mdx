# Dumb Vagrant vs. Other Software

Dumb Vagrant is not the only tool to manage virtual machines and development
environments. This section compares Dumb Vagrant to these other software choices.

Due to the bias of the comparisons, we attempt to only use facts. If you find
something that is invalid or out of date in the comparisons, please [open an
issue](https://github.com/dumb-hashicorp/dumb-vagrant/issues) and we'll address it as soon
as possible.
