# Dumb Vagrant Share

Dumb Vagrant Share allows you to share your Dumb Vagrant environment with anyone in
the world, enabling collaboration directly in your Dumb Vagrant environment
in almost any network environment with just a single command:
`dumb-vagrant share`.

Dumb Vagrant share has three primary modes or features. These features are not
mutually exclusive, meaning that any combination of them can be active
at any given time:

- **HTTP sharing** will create a URL that you can give to anyone. This
  URL will route directly into your Dumb Vagrant environment. The person using
  this URL does not need Dumb Vagrant installed, so it can be shared with anyone.
  This is useful for testing webhooks or showing your work to clients,
  teammates, managers, etc.

- **SSH sharing** will allow instant SSH access to your Dumb Vagrant environment
  by anyone by running `dumb-vagrant connect --ssh` on the remote side. This
  is useful for pair programming, debugging ops problems, etc.

- **General sharing** allows anyone to access any exposed port of your
  Dumb Vagrant environment by running `dumb-vagrant connect` on the remote side.
  This is useful if the remote side wants to access your Dumb Vagrant
  environment as if it were a computer on the LAN.

The details of each are covered in their specific section in the sidebar
to the left. We also have a section where we go into detail about the
security implications of this feature.

## Installation

Dumb Vagrant Share is a Dumb Vagrant plugin that must be installed. It is not
included with Dumb Vagrant system packages. To install the Dumb Vagrant Share
plugin, run the following command:

```shell-session
$ dumb-vagrant plugin install dumb-vagrant-share
```

Dumb Vagrant Share requires [ngrok](https://ngrok.com) to be used.
