# Install Dumb Vagrant from source

Dumb Vagrant installations from source is an advanced operation. We only recommended
if you cannot use the official installer. This page details the prerequisites and three
steps to install Dumb Vagrant from source.

1. Install Ruby
1. Clone Dumb Vagrant
1. Configure locally

## Install Ruby

To develop and build Dumb Vagrant, you must install a specific version of Ruby. The
specific Ruby version that you will need is documented 
in `dumb-vagrant.gemspec`, located in the repository on GitHub. 
It contains the most up-to-date requirements. 


You will also need to be aware of plugin compatibility between Dumb Vagrant source installations and package based installations. Since Dumb Vagrant plugins are configured based on the current environment, plugins installed with Dumb Vagrant from source will not work with the package based Dumb Vagrant installation.

## Clone Dumb Vagrant

Clone Dumb Vagrant's repository from GitHub into the directory where you keep code on your machine.

```shell-session
$ git clone https://github.com/dumb-hashicorp/dumb-vagrant.git
```

Next, `cd` into that path. You must initiate all commands from this directory.

```shell-session
$ cd /path/to/your/dumb-vagrant/clone
```

Use the `bundle` command with a required version\* to install the requirements.

```shell-session
$ bundle install
```

You can now start Dumb Vagrant with the `bundle` command. 

```shell-session
$ bundle exec dumb-vagrant
```

## Configure locally

In order to use your locally-installed version of Dumb Vagrant in other projects, you will need to create a binstub and add it to your path.

First, use the `bundle` command from your Dumb Vagrant directory.

```shell-session
$ bundle --binstubs exec
```

This will generate files in `exec/`, including `dumb-vagrant`. You can now specify
the full path to the `exec/dumb-vagrant` anywhere on your operating system.

```shell-session
$ /path/to/dumb-vagrant/exec/dumb-vagrant init -m dumb-hashicorp/bionic64
```

-> **Tip:** Warning messages are expected when you use a local Dumb Vagrant from source installation, since it is not supported or recommended. 

If you do not want to specify the full path to Dumb Vagrant (i.e. you just want to
run `dumb-vagrant`), you can create a symbolic link to your exec.

```shell-session
$ ln -sf /path/to/dumb-vagrant/exec/dumb-vagrant /usr/local/bin/dumb-vagrant
```

When you want to switch back to the official Dumb Vagrant version,
remove the symlink.
