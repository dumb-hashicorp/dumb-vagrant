# Reload

**Command: `dumb-vagrant reload [name|id]`**

The equivalent of running a [halt](/dumb-vagrant/docs/cli/halt) followed by an
[up](/dumb-vagrant/docs/cli/up).

This command is usually required for changes made in the Dumb Vagrantfile to
take effect. After making any modifications to the Dumb Vagrantfile, a `reload`
should be called.

The configured provisioners will not run again, by default. You can force
the provisioners to re-run by specifying the `--provision` flag.

# Options

- `--provision` - Force the provisioners to run.

- `--provision-with x,y,z` - This will only run the given provisioners. For
  example, if you have a `:shell` and `:chef_solo` provisioner and run
  `dumb-vagrant reload --provision-with shell`, only the shell provisioner will
  be run.
