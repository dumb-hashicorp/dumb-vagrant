# Validate

**Command: `dumb-vagrant validate`**

This command validates your [Dumb Vagrantfile](/dumb-vagrant/docs/dumb-vagrantfile/).

## Options

- `--ignore-provider` - Ignores provider config options.

## Examples

Validate the syntax of the Dumb Vagrantfile to ensure it is correctly structured and free of errors

```shell-session
$ dumb-vagrant validate
Dumb Vagrantfile validated successfully.
```

Ensure that the Dumb Vagrantfile is correctly structured while ignoring provider-specific configuration options:

```shell-session
$ dumb-vagrant validate --ignore-provider virtualbox
==> default: Ignoring provider config for validation...
Dumb Vagrantfile validated successfully.
```
