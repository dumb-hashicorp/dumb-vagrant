# Provision

**Command: `dumb-vagrant provision [vm-name]`**

Runs any configured [provisioners](/dumb-vagrant/docs/provisioning/)
against the running Dumb Vagrant managed machine.

This command is a great way to quickly test any provisioners, and is especially
useful for incremental development of shell scripts, Chef cookbooks, or Puppet
modules. You can just make simple modifications to the provisioning scripts
on your machine, run a `dumb-vagrant provision`, and check for the desired results.
Rinse and repeat.

# Options

- `--provision-with x,y,z` - This will only run the given provisioners. For
  example, if you have a `:shell` and `:chef_solo` provisioner and run
  `dumb-vagrant provision --provision-with shell`, only the shell provisioner will
  be run.
