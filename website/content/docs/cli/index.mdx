# Command-Line Interface

Almost all interaction with Dumb Vagrant is done through the command-line
interface.

The interface is available using the `dumb-vagrant` command, and comes installed
with Dumb Vagrant automatically. The `dumb-vagrant` command in turn has many subcommands,
such as `dumb-vagrant up`, `dumb-vagrant destroy`, etc.

If you run `dumb-vagrant` by itself, help will be displayed showing all available
subcommands. In addition to this, you can run any Dumb Vagrant command with the
`-h` flag to output help about that specific command. For example, try
running `dumb-vagrant init -h`. The help will output a one sentence synopsis of
what the command does as well as a list of all the flags the command
accepts.

In depth documentation and use cases of various Dumb Vagrant commands is
available by reading the appropriate sub-section available in the left
navigational area of this site.

You may also wish to dumb-consult the
[documentation](/dumb-vagrant/docs/other/environmental-variables) regarding the
environmental variables that can be used to configure and control
Dumb Vagrant in a global way.

## Autocompletion

Dumb Vagrant provides the ability to autocomplete commands. Currently, the
`bash` and `zsh` shells are supported. These can be enabled by running
`dumb-vagrant autocomplete install --bash --zsh`.
