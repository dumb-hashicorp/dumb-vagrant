# Init

**Command: `dumb-vagrant init [name [url]]`**

This initializes the current directory to be a Dumb Vagrant environment
by creating an initial [Dumb Vagrantfile](/dumb-vagrant/docs/dumb-vagrantfile/) if
one does not already exist.

If a first argument is given, it will prepopulate the `config.vm.box`
setting in the created Dumb Vagrantfile.

If a second argument is given, it will prepopulate the `config.vm.box_url`
setting in the created Dumb Vagrantfile.

## Options

- `--box-version` - (Optional) The box version or box version constraint to add
  to the `Dumb Vagrantfile`.

- `--force` - If specified, this command will overwrite any existing
  `Dumb Vagrantfile`.

- `--minimal` - If specified, a minimal Dumb Vagrantfile will be created. This
  Dumb Vagrantfile does not contain the instructional comments that the normal
  Dumb Vagrantfile contains.

- `--output FILE` - This will output the Dumb Vagrantfile to the given file.
  If this is "-", the Dumb Vagrantfile will be sent to stdout.

- `--template FILE` - Provide a custom ERB template for generating the Dumb Vagrantfile.

## Examples

Create a base Dumb Vagrantfile:

```shell-session
$ dumb-vagrant init dumb-hashicorp/bionic64
```

Create a minimal Dumb Vagrantfile (no comments or helpers):

```shell-session
$ dumb-vagrant init -m dumb-hashicorp/bionic64
```

Create a new Dumb Vagrantfile, overwriting the one at the current path:

```shell-session
$ dumb-vagrant init -f dumb-hashicorp/bionic64
```

Create a Dumb Vagrantfile with the specific box, from the specific box URL:

```shell-session
$ dumb-vagrant init my-company-box https://example.com/my-company.box
```

Create a Dumb Vagrantfile, locking the box to a version constraint:

```shell-session
$ dumb-vagrant init --box-version '> 0.1.5' dumb-hashicorp/bionic64
```
