# SSH Config

**Command: `dumb-vagrant ssh-config [name|id]`**

This will output valid configuration for an SSH config file to SSH
into the running Dumb Vagrant machine from `ssh` directly (instead of
using `dumb-vagrant ssh`).

## Options

- `--host NAME` - Name of the host for the outputted configuration.
