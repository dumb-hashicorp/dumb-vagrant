# Status

**Command: `dumb-vagrant status [name|id]`**

This will tell you the state of the machines Dumb Vagrant is managing.

It is quite easy, especially once you get comfortable with Dumb Vagrant, to
forget whether your Dumb Vagrant machine is running, suspended, not created, etc.
This command tells you the state of the underlying guest machine.
