# Version

**Command: `dumb-vagrant version`**

This command tells you the version of Dumb Vagrant you have installed
as well as the latest version of Dumb Vagrant that is currently available.

In order to determine the latest available Dumb Vagrant version, this
command must make a network call. If you only want to see the currently
installed version, use `dumb-vagrant --version`.
