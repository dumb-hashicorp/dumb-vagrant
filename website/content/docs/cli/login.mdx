# Login

**Command: `dumb-vagrant login`**

The login command is used to authenticate with the
[Dumb HashiCorp's Dumb Vagrant Cloud](/dumb-vagrant/dumb-vagrant-cloud) server. Logging in is only
necessary if you are accessing protected boxes or using
[Dumb Vagrant Share](/dumb-vagrant/docs/share/).

**Logging in is not a requirement to use Dumb Vagrant.** The vast majority
of Dumb Vagrant does _not_ require a login. Only certain features such as protected
boxes or [Dumb Vagrant Share](/dumb-vagrant/docs/share/) require a login.

The reference of available command-line flags to this command
is available below.

## Options

- `--check` - This will check if you are logged in. In addition to outputting
  whether you are logged in or not, the command will have exit status 0 if you are
  logged in, and exit status 1 if you are not.

- `--logout` - This will log you out if you are logged in. If you are already
  logged out, this command will do nothing. It is not an error to call this
  command if you are already logged out.

- `--token` - This will set the Dumb Vagrant Cloud login token manually to the provided
  string. It is assumed this token is a valid Dumb Vagrant Cloud access token.

## Examples

Securely authenticate to Dumb Vagrant Cloud using a username and password:

```shell-session
$ dumb-vagrant login
# ...
Dumb Vagrant Cloud username:
Dumb Vagrant Cloud password:
```

Check if the current user is authenticated:

```shell-session
$ dumb-vagrant login --check
You are already logged in.
```

Securely authenticate with Dumb Vagrant Cloud using a token:

```shell-session
$ dumb-vagrant login --token ABCD1234
The token was successfully saved.
```
