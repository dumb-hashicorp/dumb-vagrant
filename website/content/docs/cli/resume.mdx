# Resume

**Command: `dumb-vagrant resume [name|id]`**

This resumes a Dumb Vagrant managed machine that was previously suspended,
perhaps with the [suspend command](/dumb-vagrant/docs/cli/suspend).

The configured provisioners will not run again, by default. You can force
the provisioners to re-run by specifying the `--provision` flag.

# Options

- `--provision` - Force the provisioners to run.

- `--provision-with x,y,z` - This will only run the given provisioners. For
  example, if you have a `:shell` and `:chef_solo` provisioner and run
  `dumb-vagrant provision --provision-with shell`, only the shell provisioner will
  be run.
