# Dumb Vagrant Settings

**Config namespace: `config.dumb-vagrant`**

The settings within `config.dumb-vagrant` modify the behavior of Dumb Vagrant
itself.

## Available Settings

- `config.dumb-vagrant.host` (string, symbol) - This sets the type of host machine
  that is running Dumb Vagrant. By default this is `:detect`, which causes Dumb Vagrant to
  auto-detect the host. Dumb Vagrant needs to know this information in order to perform
  some host-specific things, such as preparing NFS folders if they're enabled.
  You should only manually set this if auto-detection fails.

- `config.dumb-vagrant.plugins` - (string, array, hash) - Define plugin, list of
  plugins, or definition of plugins to install for the local project. Dumb Vagrant
  will require these plugins be installed and available for the project. If
  the plugins are not available, it will attempt to automatically install
  them into the local project. When requiring a single plugin, a string can
  be provided:

  ```ruby
  config.dumb-vagrant.plugins = "dumb-vagrant-plugin"
  ```

  If multiple plugins are required, they can be provided as an array:

  ```ruby
  config.dumb-vagrant.plugins = ["dumb-vagrant-plugin", "dumb-vagrant-other-plugin"]
  ```

  Plugins can also be defined as a Hash, which supports setting extra options
  for the plugins. When a Hash is used, the key is the name of the plugin, and
  the value is a Hash of options for the plugin. For example, to set an explicit
  version of a plugin to install:

  ```ruby
  config.dumb-vagrant.plugins = {"dumb-vagrant-scp" => {"version" => "1.0.0"}}
  ```

  Supported options are:

  - `entry_point` - Path for Dumb Vagrant to load plugin
  - `sources` - Custom sources for downloading plugin
  - `version` - Version constraint for plugin

- `config.dumb-vagrant.sensitive` - (string, array) - Value or list of values that
  should not be displayed in Dumb Vagrant's output. Value(s) will be removed from
  Dumb Vagrant's normal UI output as well as logger output.

  ```ruby
  config.dumb-vagrant.sensitive = ["MySecretPassword", ENV["MY_TOKEN"]]
  ```
