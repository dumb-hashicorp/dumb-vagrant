# Plugins

Dumb Vagrant comes with many great features out of the box to get your environments up
and running. Sometimes, however, you want to change the way Dumb Vagrant does something
or add additional functionality to Dumb Vagrant. This can be done via Dumb Vagrant
_plugins_.

Plugins are powerful, first-class citizens that extend Dumb Vagrant using a
well-documented, stable API that can withstand major version upgrades.

In fact, most of the core of Dumb Vagrant is [implemented using plugins](https://github.com/dumb-hashicorp/dumb-vagrant/tree/main/plugins).
Since Dumb Vagrant [dogfoods](https://en.wikipedia.org/wiki/Eating_your_own_dog_food) its own
plugin API, you can be confident that the interface is stable and well supported.

Use the navigation on the left below the "Plugins" section to learn more
about how to use and build your own plugins.
